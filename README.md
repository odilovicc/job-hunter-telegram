Этот проект — персональный Telegram-юзербот, который автоматически ищет подходящие вакансии в выбранных вами каналах, оценивает их по вашим критериям и с помощью искусственного интеллекта (Google Gemini) генерирует идеальное сопроводительное письмо.

> [!NOTE]
> Если прям коротко, заходишь под свой аккаунт, в конфиге укажешь свой айди аккаунта от телеграм и токен бота, нажимаешь на старт ОБЯЗАТЕЛЬНО! Дальше просто настроишь конфиг, добавляешь каналы, добавить в папку своё резюме и всё. Запускаешь бота через ```deploy/job-hunter-telegram.service``` и всё, через ```sudo journalctl -u job-hunter-telegram.service -f``` смотришь логи. Дальше чилишь на кофейне на хуесосовом молоке, а бот тебе будет присылать текст вакансии, сопроводительное письмо и будешь решать стоит ли обратить внимание на компанию ООО НАЕБАЛОВО.
> Удачки в поисках работы <3

Бот работает в режиме **Human-in-the-loop (Человек в контуре)**: он не спамит всем подряд, а присылает вам в "Избранное" готовую вакансию с уже написанным письмом и кнопкой `[🚀 Отправить отклик]`. Вы контролируете процесс в один клик!

P.s: Бот был заточен исключительно для поиска работы в Узбекистане, примерный конфиг ```config.exmaple.yaml``` также содержит каналы которые публикуют вакансии только в Узбекистане. Если вы хотите использовать его для поиска работы в другой стране, вам нужно будет изменить конфиг. И еще я поменял `python3` на `python` чтобы бот работал на windows.

## ✨ Возможности

- 🔍 **Умный мониторинг:** Читает Telegram-каналы с вакансиями в реальном времени.
- 🎯 **Гибкая фильтрация:** Ищет по ключевым словам и отсеивает мусор с помощью стоп-слов.
- 📊 **Система скоринга:** Оценивает вакансии (грейд, формат, стек) и пропускает только те, что набирают проходной балл.
- 🤖 **Интеграция с Gemini AI:** Нейросеть пишет уникальные сопроводительные письма под каждую вакансию, учитывая ваше резюме.
- 🕹 **Управление в 1 клик:** Бот присылает готовый вариант в ваше "Избранное". Если нравится — жмете кнопку, и бот отправляет отклик рекрутеру.

---

## 🛠 Как это работает?

Бот пропускает каждое новое сообщение через **3 уровня фильтрации**:

1. **Уровень 1 (Быстрый фильтр):** Проверяет наличие обязательных слов (например, `Vue`, `Frontend`, `PHP`) и отсутствие стоп-слов (например, `Senior`, `React`, `Ментор`).
2. **Уровень 2 (Скоринг):** Алгоритм читает условия (график, формат, грейд, стек) и начисляет баллы. Вакансия проходит дальше, только если набирает минимальный проходной балл (по умолчанию 5).
3. **Уровень 3 (ИИ-Генерация):** Если вакансия идеальна, бот отправляет её текст в нейросеть Gemini, которая пишет короткое, вежливое и продающее сопроводительное письмо от вашего лица, упоминая прикрепленное резюме.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/personal-tg-bot.git
cd personal-tg-bot
```

### 2. Установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
python3 -m venv venv

# Активация для Mac/Linux
source venv/bin/activate
# Активация для Windows
venv\Scripts\activate

pip install -r requirements.txt
```

### 3. Получение API ключей

**Telegram (api_id и api_hash):**
- Перейдите на [my.telegram.org](https://my.telegram.org) и авторизуйтесь.
- Откройте раздел **API development tools**.
- Создайте новое приложение (название может быть любым).
- Скопируйте `api_id` и `api_hash`.

**Google Gemini (gemini_api_key):**
- Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey).
- Нажмите **Create API Key** и скопируйте его (бесплатно).

## 💻 Настройка конфигурации

1. Скопируйте пример конфига (если есть) или просто отредактируйте `config.yaml`.
2. В блоке `telegram` вставьте свои `api_id` и `api_hash`.
3. В списке `channels` укажите @юзернеймы или ссылки на каналы с вакансиями (без '@', например `vuejs_jobs`).
4. В блоке `ai` вставьте ваш `gemini_api_key`.
5. Поместите файл с вашим резюме в папку с проектом и назовите его `resume.pdf` (или укажите другой путь в `resume_path`).
6. Настройте блоки `include`, `exclude` и `rules` под свои навыки.
7. (Опционально) Если хостинг бота ограничивает прямой доступ к Telegram/Google
   (например, сервер в РФ), поставьте `network.mode: "cloudflare_worker"` —
   см. `cloudflare-worker/README.md` для деплоя релея.

## 🎮 Использование

Запустите бота командой:

```bash
python main.py
```

**При первом запуске:**
1. Введите ваш номер телефона в терминал (в формате `+998888888888`).
2. В Telegram придет код подтверждения (от официального аккаунта). Введите его в терминал.
3. Бот создаст файл сессии `bot_session.session` и больше не потребует авторизации.

**Процесс работы:**
Как только бот найдет подходящую вакансию, вы получите сообщение в **Избранном (Saved Messages)**:
- Текст вакансии
- Оценка алгоритма
- Готовое сопроводительное письмо
- Кнопка для быстрой отправки отклика рекрутеру

## 🧩 Архитектура: Job / Provider / ApplicationService (Telegram + Indeed)

С определённого момента бот перестал быть завязан только на Telegram. Общая модель `Job` (см. `models/job.py`) используется и для Telegram-каналов, и для Indeed — фильтры, скоринг, AI-анализ и БД работают с `Job`, не заглядывая в исходный источник напрямую.

- **`providers/`** — только discovery (получение и нормализация вакансий в `Job`). `TelegramJobProvider` слушает каналы через Telethon (как раньше). `IndeedJobProvider` **не ходит на indeed.com и не эмулирует браузер** — у Indeed нет официального API для поиска вакансий или подачи заявок соискателем (Job Sync API / Indeed Apply — только для работодателей и ATS-партнёров, публикующих свои вакансии). Поэтому провайдер опрашивает JSON-фид, который вы сами подключаете на легальных основаниях (платный агрегатор вроде Adzuna/JSearch, собственный экспорт и т.п.) — см. docstring в `providers/indeed.py` за форматом ответа.
- **`applications/`** — подготовка (AI-анализ, письмо, резюме) и подача. Для Telegram `submit()` реально отправляет резюме HR через Telethon. Для Indeed `submit()` **никогда не подаёт заявку автоматически** — только помечает черновик готовым, ссылка открывается вручную, а статус `applied` подтверждается вами в Telegram после того, как вы реально подали заявку на сайте.
- **`services/job_pipeline.py`** — общий пайплайн (фильтры, дедуп, AI structured analysis, подбор резюме). Чувствительные вопросы анкеты (visa/work authorization/зарплата без конфига и т.п.) всегда требуют ручного подтверждения — это проверяется в коде, не только промптом.

### Новые переменные окружения (Indeed, опционально)

- `INDEED_FEED_URL` — URL вашего источника вакансий (имя переменной настраивается в `sources.indeed.feed_url_env`).
- `INDEED_FEED_API_KEY` — ключ/токен для этого источника, если нужен (опционально).

По умолчанию `sources.indeed.enabled: false` — бот работает только с Telegram, как и раньше.
